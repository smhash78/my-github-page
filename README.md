## Selected Projects

### Conversational Search System using RAG
Developed a retrieval-augmented conversational agent using transformer embeddings on the CMU Book Summaries dataset, integrating a vector DB with hybrid semantic retrieval for relevance and performance evaluation.

### Real-Time Collective Sentiment Analysis System for Twitter Streams
Built a real-time system to analyze and visualize collective sentiment across multiple Twitter streams for multiple end users using Apache Kafka and TinyBERT.

### Taxonomy Discovery in Ontologies Using Large Language Models
Designed a classification-based system for taxonomy discovery with fine-tuned BERT-Large, demonstrating that our system achieved performance comparable to the much larger LLaMA 3 70B.
- 1st place, [LLMs4OL 2024 Challenge](https://sites.google.com/view/llms4ol/) Task B (Geonames Ontology)
- [Paper](https://www.tib-op.org/ojs/index.php/ocp/article/view/2483) published in Open Conference Proceedings

### Persian Paraphrase Detection using Deep Learning
Fine-tuned ParsBERT on a subset of the Degarbayan-SC dataset for paraphrase detection, achieving an F1-score of 98.4% on Degrabayan-SC and 90.1% on ExaPPC, showcasing the model’s effectiveness and cross-dataset generalization.
